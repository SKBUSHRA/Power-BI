<h1>Staffing Data Dashboard</h1>
<p>Staffing Dashboard has HR staffing data. It has staffing and its performance reports.</p>
<p>In staffing the Report shows count of Staff by age and department, Average Salary by department, Gender distribution in each department.</p>
<p>In Staff performance report, it displays the score card which displays the Sum of Salaries between two countries, Top performers in each country and the year wise growth of the firm.

<h1>SuperMarket Sales Dashboard</h1>
<p>SuperMarket dashboard has Supermarket orders, returns, Customer, Products and Region data.</p>
<p>The dashboard leads with a Total Sales KPI, providing an immediate snapshot of the organization's top-line revenue.
To provided targeted analysis, the report features a Dynamic Regional Multi-Filter which allows users to check the performance across specific regions.
Key geographic insights include:
Top 5 High-Performing Countries highlighting the leading markets by sales volume.
Users can utilize Drill-Down functionality to explore sub-regional data or Drill-Through to access underlying transaction-level details for any specific country.
The report features a specialized Country-Level Drill-Through, which navigates the user to a detailed profile of the top 10 customers within that market. This view includes a Customer Spending Behavior Analysis, providing a qualitative breakdown of purchasing patterns and individual customer contributions.
Sales Performance Line Chart tracks revenue fluctuations over time, enabling leadership to identify patterns, growth and anomalies if any.
Products report displays the heat map with Top 10 selling products and the total profit KPI.
Shipping report displays the shipping and returns report. Displays variable returns and shipping with different measures.
</p>
